# Yanzhe Ji’s academic homepage

A static site for GitHub Pages. Open `index.html` in a browser to preview it locally. The site uses a locally stored illustration and a system font fallback if Google Fonts is unavailable.

## Updating the site

- Edit `index.html` to update the bio, research interests, papers, or profile links.
- Edit `styles.css` to change the layout and visual style.
- To add a public CV, place `cv.pdf` alongside `index.html` and add a link to it in the hero or contact section.

## GitHub Pages

Put the files in the root of the `jilly6/jilly6.github.io` repository. In **Settings → Pages**, choose **Deploy from a branch** and select **main / (root)**.

## Illustration

The hero image, `robot-studio.jpg`, was generated with ImageGen from a brief for a 4:3 studio illustration of an ivory and cobalt robotic arm positioning a translucent apricot sphere against a pale periwinkle backdrop.
